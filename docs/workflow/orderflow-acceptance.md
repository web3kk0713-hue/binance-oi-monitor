- 本地 `pnpm test`：17个测试文件、198项通过（18:39最终全量回归）；`pnpm build`、`git diff --check` 通过。构建保留 ECharts 公共渲染包大于500kB的体积提示，页面与图表已经延迟加载。
- 真实公共流先连续运行六分钟，收到大额买卖、持续压力等实际事件；初版探测见 `flow-runtime-probe.json`。该初版只发现548合约，后续集合比对定位到单字符资产、U报价及中文币名的校验遗漏，已修复，不将早期覆盖结果冒充最终全量结果。
- 最终本机后台实测568合约+1个核实现货，与OI目录逐项一致；13路连接。真实两次OI完成时间相差29.161秒。后台运行与重启证据见 `flow-backend-acceptance.md`。
- 真实重启及只读再启动：7张flow表数量和内容哈希一致；只读实例不发起上游采集、旧快照明确断连。事件基础证据冻结，结果仅追加，未回写当时尚未知的信息。
- 桌面及390px移动界面：异常列表、真实大额成交点击回放、K线/气泡/Delta/CVD/OI联动、1m/5m切换、7天选择、明确历史不足提示已在浏览器验证。没有创建假事件以填充首屏。操作系统权限未代替用户开启；真实系统通知送达不计为已验证。

## 已修复的故障边界

- REST回补不能覆盖闭合分钟首次接收时间，避免历史回放在刷新后消失。
- 关闭feed等待在途及最后一批观测写入；暂时写库失败保留同批重试。
- 断线、页面休眠、深度序列断档立即停止相关判断；盘口重新建立基准。
- 高活跃币的有界成交样本不会因不足五分钟源跨度而永久预热；连续连接时长与样本统计跨度分别处理。
- 预启动spot深链接经已确认合约身份解析；现货目录临时错误限次退避，地区限制不绕过。
- 市场目录变动同步更新订阅，避免下线再上线双重采集。
- 事件历史支持半小时范围；请求超限正确返回429。前后端回放同时检查源时间、接收时间和结果可用时间。
