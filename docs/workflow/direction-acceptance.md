# 当前方向建议：增量实现与验收

## 范围与授权

2026-09-25 用户要求在变化监控和异常监控显眼写出建议多或空。沿用既有源头数据、React/TypeScript、两页结构与 GitHub Pages 发布授权。此项在既有“仅观察标签”之外增加独立实验性方向候选层；不改变 OI/FDV 告警含义，不新增交易权限、付费服务、云端后台或关页推送。

设计沿用已批准的 Apple HIG / TradingView 工作台参照：详情内一条醒目方向带，列表文字标签，绿色偏多、红色偏空、灰色观望；理由、缺确认、风险和撤销条件可直接看到，详细规则折叠。颜色不是唯一编码。

## 规则合同

`assessDirection` 是共享纯函数，只接受当前 FlowSnapshot、assetId、当前时刻和可选的明确交易对。两页共享，不建立新采集连接。

- 固定5分钟：同一合约最近5根已闭合1m的价格/主动成交；OI使用原引擎在闭合边界附近的连续实测变化，至少10个观测且相邻间隔≤45秒；不把自定义1h/7d端点或币种聚合量拼接进方向判断。
- OI数量增加≥5%，价格>+0.5%，主动买≥60%、成交差额>0：偏多候选。
- OI数量增加≥5%，价格<−0.5%，主动买≤40%、成交差额<0：偏空候选。
- 减仓、价格死区、条件不齐、冲突、源行情失效：观望。不会因缩仓直接声称回补或清算。
- 现货确认须同资产、同计价币、同闭合窗口。主动买≥55%且价格>0 / 主动买≤45%且价格<0为同向；反向压力或反向价格撤销候选。未知、中性、未覆盖标待确认，不能称作已确认。
- 快照/市场快照新鲜度≤30秒，K线源时间≤90秒，必须source≤asOf≤snapshot≤now；原flow engine还有更严格的连续性/实时门槛。无效数据留空，不复用旧推荐。闭合窗口由引擎floor(asOf/60000)契约推出，不把可能属于未闭合K线的lastCandleAt当终点。
- FDV及OI/FDV不作为独立方向票。资金费率只展示风险，不用符号反推方向，不用未经单独核验的周期缓存判定拥挤。未评价执行价格、盘口、成本和仓位。
- 历史事件列表展示的是明确标注更新时间的“当前5m”判断；回放和导出保留非事件时点提示。不使用未来event.outcomes，不制造历史建议。

所有门槛均为初始经验筛选参数，尚无扣费后回测、胜率或风险收益验证。规则撤销候选不是止损或自动平仓。

定义复核（2026-09-25）：[CME Open Interest](https://www.cmegroup.com/education/lessons/open-interest)、[Binance Funding Rates](https://www.binance.com/en/support/faq/detail/360033525031)。这些来源支持字段含义，不为本项目阈值或预测能力背书。

## 验收记录

- 本地回归：30 个测试文件、598 项通过（`pnpm exec vitest run --maxWorkers=2`）；类型检查和生产构建通过。方向与显示新增90项验证，覆盖对称阈值、空/未来/过期值、现货冲突、显式交易对身份、计价币与窗口错配、资金费率、当前/历史分离。图表依赖仍有既有的大于500KB分块提示，不是构建失败。
- 隔离浏览器：9 个合成币种、15 个市场、3 个事件。变化页验证偏多、偏空、冲突观望、单合约OI缺失不借用聚合OI；改为60m筛选仍明确显示独立固定5m建议。异常页事件标签、详情与回放警告一致。
- 过期恢复：验收服务切为120秒旧快照后，详情和事件列表的候选均撤销为观望；恢复新鲜输入后恢复正常判断。
