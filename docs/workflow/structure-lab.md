# 结构建议验证版

2026-09-28 用户确认开发；明确目前没有后台。范围是结构化候选建议、历史回放、影子验证，不替换正式提醒，不自动交易。本轮未授权发布或云资源开通。

## 增量设计与边界

- 复用 TypeScript / React / Vite、decimal.js、ECharts、IndexedDB 和现有公共行情。无新依赖、不更换健康架构、不升级交易权限。
- `structureTypes.ts` 固定独立数据契约。候选建议不实现 `RiskPlanDraft`，不可由正式计划确认入口采纳。观察记录放独立 IndexedDB，不改现有持仓数据库。
- 按需从币安官方 `markPriceKlines` 加载单合约 14 天已收盘 5m 标记价，前 7 天可作历史准备，后 7 天可回放；不把浏览器缓存称为云端历史数据库。只有有限后台权重预算，不竞争全市场 OI 请求。
- 候选核心：过去 7 天已确认 15m 摆动点，左右各 2 根，剔除确认后已被已收盘价穿越的结构；ATR14 简单平均缓冲取 0.25 倍且不少于 2 tick。最近有效对侧结构目标不足 1.2 倍剩余风险时不给方案。参数仅为研究基线，不是已验证最优值。价格按交易 tick 保守取整后重新检查空间。
- 显示 5m/15m/1h/4h 已闭合背景；只作价格背景，不假装独立方向投票。缺失历史 OI/资金费等不补造，也不将当前辅助信息注入历史回放。
- 回放使用当时收盘参考价模拟新开仓，不把用户如今的真实开仓价套入过去；只判断未来 5m OHLC 触线，双触线先后未知，不计算胜率、净收益、成交或强平。只用当时之前的信息生成价位。
- 影子记录在用户点击后冻结，7 天以上保留（至本机容量上限时停止新增，不静默删）；页面打开时复用约 5 秒一次的最新标记价快照，并非完整 1 秒消息日志，采样间短暂触线可能遗漏。只记研究结果，不弹正式离场通知。刷新/断流后标记覆盖缺口，不回填成持续在线。已离场仓位保留只读记录入口，不再拉历史。
- 计算通过同源 Web Worker 按需运行；同一时刻仅一个活跃任务和一个最新排队任务，滑动产生的过时排队任务取消。浏览器不支持或线程出错时明确失败，不退回主线程阻塞 UI。

## 界面计划

沿用现有 Apple 风格浅色工作台和已批准 TradingView / Coinbase 分区，不引入仪表盘模板。背景 #f5f5f7，内容 #ffffff，正文 #1d1d1f，次要文字 #6e6e73，动作蓝 #0875e1，风险琥珀 #976400；系统中文字体与表格数字。仓位右侧一个“结构验证”入口；展开后“当前候选 / 历史回放 / 观察记录”切换，同一图内对齐标记价、止损和目标，三项关键价格优先，方法/原始口径折叠。无装饰动画、无额外英雄区，移动端上下排列。

参考：既有持仓 UI；TradingView Bar Replay（https://www.tradingview.com/support/solutions/43000712747-bar-replay-how-and-why-to-test-a-strategy-in-the-past/）借鉴独立历史时点与向后推进；Apple Charts 页面当前需 JS，未将不可读页面当作新证据。标记价字段/5m/分页上限与权重据币安官方市场数据文档复核。

## 验收计划

测试多空、精度、止损/目标方向、亏损目标命名、未来数据隔离、缺根/冲突/历史不足、价位失效、临界 RR、候选不可正式采纳、重复/过期/乱序标记价、刷新缺口、持久化恢复、图表与窄屏。分别报告静态、集成、真实源和浏览器验收；不可用的检查不记为通过。

- 增量复核修复：回放输入按仓位标量稳定化，行情快照克隆不再强制重算/重置缩放；跨标签页尚未同步的持仓仅标记缺口，不误判已离场；返回的保存结果深拷贝，外部引用不能改变冻结展示；生成数值与持久化范围/Decimal 运算逐项一致校验。
