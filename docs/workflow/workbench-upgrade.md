# 2026-09-25 已确认工作台升级

## 批准范围

用户确认“市场机会 / 我的持仓 / 风险提醒”的简洁工作台。手动录入标的、方向、开仓价、开仓保证金和杠杆；系统提出可编辑风险草案，用户确认具体方案后启用止损/止盈/移动保护及信号减弱提醒，不自动交易。继续既有 GitHub Pages 发布目标。新云资源、凭证、交易所私密 API 和自动交易不在本阶段。

用户追加明确要求：不清晰的指标全部用气泡说明，支持手机点按，不靠长段落解释操作。重要数据失效和监控限制直接可见。

## 实现合同与设计

- 保留 React 19 / Vite / TypeScript / Decimal / IndexedDB，以及既有 Node 24 / Fastify / PostgreSQL/SQLite 行情后台。无新依赖，不迁移模板或托管平台。
- 三主导航，市场机会内保留变化、异常、OI 与估值；方向配置灵敏/标准/严格/自定义共用。变化筛选窗口与方向固定 5m 分离，不因“灵敏”放宽数据质量。
- 设计沿用浅色系统字体、蓝色操作、轻分隔和紧凑数据工作区。参考 [Apple segmented controls](https://developer.apple.com/design/human-interface-guidelines/segmented-controls) 与 [TradingView Supercharts](https://www.tradingview.com/support/solutions/43000746464-getting-started-with-supercharts/) 的分区和上下文详情，不复制品牌资产。
- 独立私密数据合同 `src/shared/positionTypes.ts`：手工 USDT 线性永续、十进制字符串、版本化计划、draft/armed/triggered/closed 状态。公开行情快照不含个人仓位。
- 估算数量=保证金×杠杆÷开仓价；PnL 根据同合约原生标记价计算，不拿归一化资产指数价/成交价/其他报价币合约替代。不估算强平价或承诺最大亏损。
- 风险草案：当前标记价 P、同合约 ATR14(SMA,15根闭合1m) A，D=2A，保护价=P−方向×D，止盈=P+方向×2D，移动激活=P+方向×D，回撤率=A/激活价×100%，草案回撤率6位有效数字。缺失或过期不自动生成替代方案。未回测，不声称最优。
- 确认采用 expectedPlanRevision 检查；每次变更重新确认。单计划每条规则仅一次事件；triggered 不代表已离场。方向减弱须有效同向基线及连续两个不同闭合分钟窗口不再支持原方向，缺数不当转弱。
- 同一 Binance mark stream 输出独立 marks，资金费率缺失不影响有效标记价。WS15秒、REST45秒新鲜度；精确源/接收时间校验。断档只判断恢复后已观测价格，不虚构触线或高低点。
- IndexedDB 独立私密库，同事务保存状态和通知 outbox；事务序列化跨标签 CAS，通知租约+固定事件tag去重，失败重试。旧事件保留历史，不当成新弹窗重播。无匿名私密数据写 API、无仓位上传或日志。
- 指标气泡说明定义、窗口、示例、限制。估值成交观察为滚动5m实际收到交易；异常成交为闭合5根1m，不能混为同一精确端点。[Binance spot trade stream字段](https://developers.binance.com/docs/binance-spot-api-docs/web-socket-streams) 中 m 标识买方是否 maker，反向推断 taker 方向；主动买入不等于开多。

## 性能与可靠性改进

- 隐藏 Flow UI 停止 UI 时钟、图表/事件/方向计算，通知 effects 继续；图表懒加载保持。无快照时变化监控停时钟。
- 按资产索引方向输入，按完整市场键在同轮复用；时间更新后重新校验过期，不跨快照无限缓存。
- 正常5秒周期发布由2次变1次，历史写入市场目录使用 getter，不再为目录生成全市场指标；有写入周期原最多3次 metrics降至1次。错误恢复/停机发布仍保留。
- 市场目录按事务内现有值写差异；600目录初始化600次put，随后12同批0次重复put。历史请求只做同范围在途去重和取消，未宣称已完成7天尾部增量缓存。

## 发布与商用边界

GitHub Pages 只托管前端。当前手工仓位是本机监控，关闭/休眠可能错过触线，即使连接行情后台也未部署认证的后台仓位引擎。系统通知需要用户授予浏览器权限，送达受浏览器/操作系统影响。未来商用仍需常驻资源、用户鉴权隔离、私密存储/备份、可观测性与告警SLO、容量/故障演练、交易所权限分离及回测；不得把本轮功能上线称为商业生产验收完成。
