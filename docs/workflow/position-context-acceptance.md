# 持仓与价格联动增量验收

2026-09-24：用户授权按已讨论建议优化，并在“变化监控”“异常监控”醒目展示。沿用 React / TypeScript / Vite、既有 Binance 行情、历史与订单流链路，不增加依赖或新上游轮询，不购买或部署云资源。

## 范围与设计

- 两页共享持仓观察面板：OI 数量涨跌幅、价格涨跌幅、美元 OI 涨跌幅、FDV 涨跌幅、OI 美元名义额 / FDV 当前百分比、占比相对变化和百分点变化。
- 变化监控沿用自定义观察窗口和原有命中参数；异常监控使用 5 分钟。联动描述以数量 OI 绝对变化至少 5%、价格绝对变化不超过 0.5% 为观察门槛，始终标明，不把固定观察门槛称为统计异常或盈利信号。
- 合约 / 现货主动买入、净主动成交额和资金费率取既有订单流。单独标记最近完整 5m K 线口径，不与快照端点假装精确同步；报价币分别展示，不混成 USD。只为当前观察标的复用现货连接。
- 颜色、字体、留白复用当前浅色系统；蓝色强调主数据、琥珀色强调待观察现象，正负号和文字共同表达方向。紧凑横向数据带、桌面表格和移动端两列布局；细节折叠，关键过期/缺失警告直接可见。
- 参考：Apple HIG Charts（https://developer.apple.com/design/human-interface-guidelines/charts）和现有已批准的 TradingView Screener / Coinbase Advanced 分区；TradingView OI 原始数量定义（https://www.tradingview.com/support/solutions/43000685269-open-interest/）。不复刻品牌。

## 数据约束

- 禁用“涨跌幅相除”的失真指标。占比相对变化 = `(OI末 / FDV末) / (OI初 / FDV初) - 1`；百分点变化为末占比减初占比。
- 同币种、同合约组成和倍率、真实可用时间、90 秒源新鲜度、30 秒源偏差及45秒基线容差复用已有规则；旧值只读兜底不进入新指标。
- FDV缺失不遮住独立有效的价格与数量OI。无起点可显示经过校验的当前占比，但变化留空。隐含供给变化提示不能把FDV全部解释为价格。
- 历史事件回放旁的当前面板标明“当前快照，不是事件触发证据”，避免前视偏差。
- 现象标签不是多空归因，不是新增资金、真实杠杆或买卖指令；价格与固定供给FDV、数量OI与占比变化高度相关，不能当作独立确认票。

## 本机验收证据（2026-09-24）

- `pnpm test` 与 `pnpm exec vitest run --maxWorkers=2`：均为28文件、508测试通过；`pnpm check` / `pnpm build` 通过。覆盖数学、边界、缺失/未来/过期/合约变化、供给变化及订单流选择。首次同时运行构建与默认全并发测试时，三个原有 HTTP listener 测试触发5秒超时；限制两个测试 worker 后全套通过，之后独立运行默认并发也全套通过，未放松时间断言。
- 独立 `server/position-ui-acceptance.ts` 本机合成夹具，监听127.0.0.1，CSP只允许同源，无上游连接、凭证或生产写入。TEST_FLAT 显示数量 +10%、价格/FDV +0.2%、美元OI +10.22%、占比11%、占比相对+10%、+1个百分点；合约/现货主动买入65%/62%，费率+0.01%、8h。
- “增仓横盘”筛选返回 TEST_FLAT 与 TEST_MISSING；后者价格/OI仍有效，FDV及占比为空。改自定义OI门槛为12%后原命中数2降为0，独立联动观察线仍明确显示5%。
- `stale` 夹具让源快照老120秒后，联动数降为0，持仓/占比/成交/资金费率全部退出当前判断；恢复`live`后自行恢复。TEST_UP估值有效但订单流故意过期，成交和资金费率保持空值。
- 两页桌面浏览器验收、390×844手机两列指标布局通过；实际文档宽375px（含滚动条空间）不超过390px视口，表格仅在内部横向滚动。回放事件旁始终有“当前快照，不是历史触发证据”的可见提示。
- 价格曲线、占比曲线开关与刷新后勾选状态验证；显示同一基线与真实历史截止时间，缺口断线。浏览器未发现JS错误。
- 独立复核修复：订单流投影以实际渲染时刻校验，避免旧定时时钟误伤新收到快照；联动标签额外检查真实OI/价格源时间差，不能仅相信存档sourceSkewMs。
- 发布步骤沿用既有GitHub Pages授权；源代码提交后核对Actions和公开页面资源版本，不在本机测试结果中预先声称线上完成。
- 保留边界：GitHub Pages不是常驻后台；浏览器关页或休眠中断采集，历史不足不会编造。
